# 🚀 AI Agent Engineering Path: De 0 a Agente IA

Bienvenido a mi repositorio de especialización en ingeniería de software e inteligencia artificial. Este monorepo documenta mi camino de aprendizaje desde los fundamentos de arquitectura limpia hasta el desarrollo de agentes autónomos complejos.

## 🎯 Visión del Proyecto

El objetivo es dominar el stack tecnológico necesario para construir un AI Personal Productivity Assistant, aplicando estándares de industria en cada paso. Este viaje está estructurado en "Asignaturas" que cubren desde la persistencia de datos hasta la orquestación de modelos de lenguaje (LLMs).
